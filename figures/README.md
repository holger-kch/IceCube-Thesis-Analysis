# Figures

This directory contains the figure assets for the GitHub version of the Master
Thesis Preparation Project.

The figures are included because they are part of the scientific argument, not
as a loose image dump. The README uses them in report order, and the figure
index connects each one to the code or source behind it.

- [report/](report/) contains the figure files used by
  `/groups/icecube/holgerkc/final/main.pdf`.
- [report_previews/](report_previews/) contains PNG previews generated from the
  report PDFs so the figures can be browsed directly on GitHub.

For figure-to-code provenance, see [docs/figure_index.md](../docs/figure_index.md).
